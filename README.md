# Resident-Evil-textures-fixer-and-adjuster
A mod that helps you replace the modded model's texture that is compatible with Resident Evil 1 Classic!


This tool is an alternative of the plugin on Photoshop, where it seems like it might not compatible with some users, of a different program requirement.

So this tool will solve this problem you can use it to be able to replace the model's texture and do some settings.

# Features

- Settings that was used from PhotoShop's plugin, so you're not required to be using photoshop.
- Save as .tim file.
- Save as .png file.
- Save as new .EMD file,
- Preview the model's texture.
- Zoom in and out (only as options).
- Open the original model as reference for your custom model, for more compatiblity.
- Highlight simi-transparent option.

In order for you to download this tool, go to [release](https://github.com/mohammedtaher991/Resident-Evil-textures-fixer-and-adjuster/releases) page.

This tool doen't require a specific program to use nor a plugin for any program.

Tools used based from AI was Pillow and numpy.
